### Source Code Files

#### `src/components/Bird.js` (147 lines)
**Purpose**: Bird component with detailed design and animation
**Features**:
- Custom bird design (body, wing, eye, beak)
- Flying animation (translateY, opacity, scale, rotation)
- Touch interaction
- 5 color variants
- Callback to parent on fly complete

**Key Functions**:
- `handlePress()` - Triggers flying animation
- `animatedStyle()` - Computes animated styles
- Bird visual components rendering

#### `src/components/Stick.js` (71 lines)
**Purpose**: Horizontal stick component
**Features**:
- Wooden stick design with shadow
- Break animation when all birds leave
- Position-based rendering

**Key Functions**:
- Break animation with opacity and scale
- Positioning based on config

#### `src/components/LevelCompleteModal.js` (147 lines)
**Purpose**: Victory celebration modal
**Features**:
- Animated entrance (scale + rotation)
- Star decorations
- Next Level and Restart buttons
- Celebration message

**Key Functions**:
- Entrance animation on visibility change
- Button callbacks for navigation

#### `src/screens/HomeScreen.js` (146 lines)
**Purpose**: Level selection screen
**Features**:
- Lists all available levels
- Shows level details (sticks count, birds count)
- Game instructions
- Beautiful card-based layout

**Key Functions**:
- `startLevel()` - Navigates to game with level ID
- Level stats calculation

#### `src/screens/GameScreen.js` (214 lines)
**Purpose**: Main gameplay screen
**Features**:
- Game loop and state management
- Bird and stick rendering
- Level completion detection
- Back navigation

**Key State**:
- `currentLevel` - Active level data
- `activeBirds` - Set of remaining bird IDs
- `brokenSticks` - Set of broken stick IDs
- `showCompleteModal` - Modal visibility

**Key Functions**:
- `handleBirdFly()` - Called when bird flies
- `handleNextLevel()` - Progress to next level  
- `handleRestart()` - Reset current level

#### `src/config/levels.js` (110 lines)
**Purpose**: Game configuration and level data
**Exports**:
- `LEVELS` - Array of 3 level configurations
- `BIRD_COLORS` - Color mapping for 5 bird types
- `GAME_CONFIG` - Global game constants

**Structure**:
```javascript
Level {
  id, name,
  sticks: [{
    id, position: {x, y},
    birds: [{ id, type, offset }]
  }]
}
```

## 📦 What Gets Built into APK

When you build the APK, these files are included:

### Included
✅ All JavaScript files (bundled)
✅ App configuration (app.json)
✅ Assets (icons, splash screens)
✅ Dependencies from node_modules

### Excluded
❌ Documentation files (.md)
❌ Source node_modules (bundled instead)
❌ Development files (.git, etc.)
❌ eas.json, babel.config.js

### Result
- **APK Size**: ~50-100 MB
- **Contents**: Optimized JavaScript bundle + React Native runtime
- **Assets**: Compressed images and fonts
